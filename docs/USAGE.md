# MuMuLink 使用教程

从零开始，10 分钟把手机变成"教室电脑上 MuMu 模拟器的屏幕 + 触控板"。

---

## 0. 你需要什么

| 项目 | 要求 |
|---|---|
| 电脑 | Windows 10/11，已装 **MuMu 模拟器 12/15**（能正常开机进桌面） |
| 手机 | Android 8.0+（本项目编译 `minSdk 26`） |
| 网络 | 手机和电脑**能互相访问**（同一 Wi-Fi 最省事；跨网段见第 5 节） |
| 不需要 | root、USB 调试、公网、云账号 |

---

## 1. 电脑端：启动代理（只做一次配置）

1. 解压 `MuMuLink-Agent-*.zip` 到任意目录（路径别含中文也行，但**不要放在 C:\\Program Files**，后面要写配置）。
2. 双击 `pc\start-agent.cmd`。
   - 第一次运行会自动准备一份本地 Node 运行时（为了满足 Windows 防火墙对"用户目录程序"的放行策略），需要十几秒。
   - 如果 Windows 弹防火墙提示，**两个复选框都勾上（专用 + 公用）→ 允许访问**。
3. 看到类似输出就成功了：

```
HTTP 已监听 0.0.0.0:27180，TCP 视频 27182 / 控制 27183
UDP 发现已监听 0.0.0.0:27181
设备状态：<机型> Android 15 1440x2560 @360dpi
配对码：000000（可在 config.json 修改）
```

> 代理是**零第三方依赖**的 Node 脚本；窗口最小化即可，不要关。崩溃会在 3 秒后自动重启。
> 想让它在登录 Windows 后自动启动：双击 `pc\install-autostart.cmd`（写入当前用户的启动项，不需要管理员）。

### 代理目录里有什么

| 文件 | 用途 |
|---|---|
| `pc\start-agent.cmd` | 启动（含崩溃自动重启） |
| `pc\config.json` | 端口、配对码、MuMu adb 地址（首次启动自动生成） |
| `pc\fix-firewall.cmd` | 万一防火墙没放行，右键"以管理员身份运行"补一条规则 |
| `pc\lib\` | 代理实现（adb / scrcpy / 显示 / 发现 / 页面） |

---

## 2. 手机端：安装并连接

1. 安装 `MuMuLink-1.1.0.apk`。
2. 手机和电脑连同一个 Wi-Fi，打开 App。
3. 有两种连法：

   **A. 自动发现（推荐，同一网段）**
   等 3–5 秒，列表里出现「客厅电脑 / 你的电脑名」→ 点它 → 输入电脑上显示的 **6 位配对码** → 连接。

   **B. 手动填 IP（跨网段 / 发现不到时）**
   展开「手动连接」→ 电脑 IP 填代理窗口里显示的地址（例如 `192.168.1.10`）→ 端口 `27180` → 配对码 → 「配对并连接」。

   也可以点「最近连接」里的历史胶囊，第二次起免配对码直连。

4. 连上后就是**沉浸式画面**：没有状态栏、没有导航栏、没有工具栏，整屏就是模拟器。

> 配对成功后会拿到一个 token 存在手机里，下次连接不用再输配对码。
> 想换电脑/重置：App 首页「最近连接 → 清除」，或删掉 `pc\config.json` 里的 `token` 后重启代理。

---

## 3. 手机上怎么操作

### 触摸
和用手机一模一样：单击、长按、滑动、双指缩放、多指操作，全部以原生触摸事件注入模拟器。

### 悬浮球（右下角，可隐藏）

| 操作 | 效果 |
|---|---|
| 点一下 | 展开 7 个功能气泡 |
| 拖动 | 移动位置（松手自动吸边） |
| 长按 | **隐藏悬浮球**（底部出现「悬浮球已隐藏 · 点此恢复」） |

7 个气泡从左到右：

| 气泡 | 作用 |
|---|---|
| 画质 | 打开串流设置面板（见下） |
| DPI | 切换「适配屏幕 / 匹配 DPI」 |
| 返回 / 主页 / 旋转 | 对应模拟器的系统键 |
| 隐藏 | 收起悬浮球 |
| 断开 | 断开串流（会二次确认） |

### 串流设置面板（点悬浮球 →「画质」，或画面顶部右侧「画质」）

- **画质四档**：流畅 / 均衡 / 高清 / 极致（预设组合，改任一项会以新参数重启会话，约 1.5 秒自动重连）。
- **自适应**：按实时网络与解码压力自动升降，手动档位会被锁定。
- **帧率**：30 / 45 / 60 / 90 / 120。
- **分辨率上限**：≤720 / ≤1080 / ≤1440 / ≤1920（指长边像素）。
- **码率**：2 / 4 / 6 / 8 / 12 Mbps。
- **显示适配**：
  - **适配屏幕（FIT）**：模拟器保持自己的分辨率与 DPI，手机按比例缩放显示（最稳，推荐默认）。
  - **匹配 DPI（MATCH）**：把模拟器 `wm size`/`wm density` 改成与手机一致，画面 1:1、字更清晰；断开后自动恢复原值。

> 校园网/弱网：先选「流畅」或打开「自适应」；宿舍串流建议码率 ≤4 Mbps。

### 断开
悬浮球 →「断开」→ 确认。电脑端会关闭 scrcpy 会话并**恢复模拟器的分辨率与 DPI**。

## 4. 电脑端还能做什么

浏览器打开 `http://<电脑IP>:27180/`：

- 查看设备与会话状态、最近日志；
- 配对（当 App 里没有配对码时，页面会显示当前配对码）；
- 「重启 scrcpy」/「停止会话」/「恢复显示」；
- **「重启模拟器（触控失灵时用）」**：见第 6 节；
- 手机浏览器打开 `http://<电脑IP>:27180/apk` 可直接下载最新 APK。

---

## 5. 网络：同一网段 / 跨网段

- **同一网段**（例如都在 `192.168.1.x`）：UDP 广播能到达 → App 自动发现，最省事。
- **跨网段**（例如教学楼 `192.168.10.x`、宿舍楼 `192.168.40.x`）：广播不跨路由器，**扫描会搜不到**，这是正常的。
  - 直接用手动连接填电脑 IP（校园网内部路由通常是通的）；
  - v1.0.1 起，扫描时还会对「最近连接过的电脑」做**单播探测**，跨网段也能发现；
  - 快速验证链路：手机浏览器打开 `http://<电脑IP>:27180/`，能看到配对页就说明通了。
- **打不开配对页** = 这条路被网络隔离（AP 客户端隔离 / ACL）。解决办法：同一 Wi-Fi、手机热点（电脑连手机）、或 USB 中转（`adb reverse`，见 FAQ）。

## 6. 常见问题

### 手机搜不到电脑
1. 先确认代理窗口还在、`HTTP 已监听 0.0.0.0:27180`；
2. 防火墙：Windows 安全中心 → 允许应用通过防火墙 → 勾选 Node（专用+公用）；或运行 `pc\fix-firewall.cmd`；
3. 跨网段：改用手动填 IP（见第 5 节）；
4. 手机连的是 5G/校园网不同 SSID：换到同一个 Wi-Fi。

### 连上了但黑屏
- 切一次画质档位（会重启会话并补关键帧）；
- 或断开重连一次；
- 仍然黑屏：看代理日志里有没有 `视频流初始 session meta`，没有就是 scrcpy 没起来，重启代理。

### **画面正常、按键可用，但点屏幕没反应**
这是模拟器端"手指停在按下状态"了（手指按着时控制连接断开导致）。v1.0.2 已修复（断开前会把手指逐根补发抬起）。
已经卡死时只能重启被控端：浏览器打开代理页面 → 「重启模拟器（触控失灵时用）」，或命令行 `mumu-cli.exe control -v 0 restart`。重启约 30–60 秒。

### 卡顿 / 花屏 / 掉帧
- 降低分辨率上限或码率（校园网建议 ≤1080p / 4 Mbps）；
- 打开「自适应」；
- MuMu 在只有核显的机器上是软解，1080p60 高码率会掉帧，属正常。

### 画面比例不对 / 有黑边
- 模拟器竖屏、手机横屏就会有黑边，属正常；
- 想铺满：用「旋转」气泡把模拟器转成和手机一致的方向，或开「匹配 DPI」。

### 怎么彻底卸载
1. 手机卸载 App；
2. 电脑：`pc\uninstall-autostart.cmd`（如果装过自启），然后删掉整个代理目录；
3. 模拟器里的临时文件：`/sdcard/mumulink/`（可删，下次会自动重推）。

## 7. 安全说明

- 所有流量都在**局域网内**，没有云端中转、没有外网穿透。
- 连接需要**配对码 + token**；视频/控制端口也会校验 token，未配对直接拒绝。
- 配对码和 token 存在 `pc\config.json`，**不要把这个文件发给别人**。
- 代理默认允许 `0.0.0.0` 监听，方便手机接入；如果你只在固定设备上用，可以在 `config.json` 里把端口改小范围并在防火墙限制来源 IP。

## 音频同步、图形化控制台与游戏模式（v1.1.0）

**听到声音**：连上后默认就带音频（代理端口 27184，48kHz 立体声）。不想要声音时：悬浮球 →「画质」→ 关掉「音频同步」。

**图形化控制台**：双击 `pc/MuMuLink-GUI.cmd`，浏览器应用窗口会打开概览页（本机打开免配对，直接进）；在那里可以复制局域网地址、看会话状态、改画质/音频、检查依赖、看日志、重启模拟器。命令行启动 `start-agent.cmd` 仍然可用。

**游戏模式**：悬浮球 →「画质」→ 打开「游戏模式」，会自动切到 1080p / 90fps / 12Mbps 并降低触控延迟；关掉即恢复常规画质。

**端口一览**：27180 HTTP/控制台，27181 UDP 发现，27182 视频，27183 控制，27184 音频，28182 仅本机 adb forward。

**注意**：跨网段（宿舍 ↔ 教室）仍请用「最近连接」或手动输入电脑 IP；UDP 广播不跨网段，这是网络本身的限制。
